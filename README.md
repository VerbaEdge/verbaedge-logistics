# VerbaEdge Trade & Logistics Technology

Public, buildless GitHub Pages source for the original **VerbaEdge** account, intended repository `VerbaEdge/verbaedge-logistics`.

Prepared from reviewed commit `45fb2c3e4dedce03652a9a1672ca78846928dff0` in `VerbaEdge/VerbaEdge.github.io`, directory `website-package/sites/logistics/`. `DEPLOYMENT_SOURCE.json` pins the 16 original site files and their SHA-256 hashes. Site content is copied byte-for-byte; this README and the manifest are deployment documentation.

Publish the contents of this directory at the repository root, preserving `.nojekyll`, assets, and page paths. GitHub Pages can deploy the approved `main` branch from `/(root)`; no build or dependency installation is needed. Use review branches and pull requests for changes.

The intended custom domain `logistics.verbaedge.com` remains planned. No `CNAME` is included: first test the temporary URL shown by Pages, then apply the separately approved custom-domain/DNS configuration and verify HTTPS. Keep the existing `verbaedge.com` homepage unchanged until both division subdomains pass their tests and main activation is approved.

Shipment and invoice-reference demonstrations use synthetic examples in the browser. They have no backend, real customer document upload, payment custody, customs filing, or certified e-invoicing service.

Only public website files are included. Private strategy, finance, governance, and personal/customer records are excluded.
